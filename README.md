# סטודיו לבנים

אפליקציה לתכנון ובנייה של דגמים מלבנים בתלת-ממד, בטלפון ובאתר.

- **האתר:** מתפרסם אוטומטית ב-GitHub Pages.
- **האפליקציה לאנדרואיד:** קובץ `BrickStudio.apk` נבנה אוטומטית ומופיע תחת Releases.

הקוד של האתר נמצא בתיקייה `web`. האפליקציה לאנדרואיד מציגה את אותו אתר מתוך הטלפון.

LEGO® הוא סימן מסחרי של קבוצת LEGO, שאינה נותנת חסות או אישור לפרויקט זה.
